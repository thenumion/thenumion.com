# NUMION — thenumion.com

Static site for GitHub Pages.

- `index.html` — home page (opens directly in a browser; needs `support.js` next to it)
- `assets/` — product photos, model photos and videos
- `CNAME` — custom domain (thenumion.com)

To replace a product photo after launch, overwrite the file in `assets/` with the same name, or upload a new file and update its path in `index.html`.
